# 0011. English as the project language

- Status: Accepted
- Date: 2026-10-18

## Context

The project is public and looks for users and contributors from any country. The initial discussion and the first version of the documentation were written in Portuguese.

## Decision

- Code, comments, commit messages, issues, pull requests, CLI and dashboard messages, and the documentation are in **English**.
- The feasibility-phase documentation, first written in Portuguese, was translated to English on 2026-10-18, before the first push.

## Consequences

- All code written from phase 1 on is in English from the start (the fixture and the spikes already are).
- Conversations with the project owner may happen in Portuguese; what goes into the repository is in English.
